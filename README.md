# Dopenomics — website

Client-facing one-page site for **Dopenomics** — operational audits, systems & infrastructure rebuilds, processes & procedures, A.I. and automation. Based in Madison, Alabama, serving the Tennessee Valley, the U.S., and internationally.

## What's in here
- **`index.html`** — the entire site, fully self-contained (inlined CSS/JS and embedded images). Open it directly in any browser to preview.
- **`netlify.toml`** — Netlify config: publishes the repo root, no build step.

## Editing
Everything lives in `index.html`. Edit it, commit, and push. Once this repo is connected to Netlify, every push to `main` redeploys the live site automatically (no more manual drag-and-drop).

## Deployment
- Hosted on **Netlify** (project: `dopenomics-website`).
- Live at **https://dopenomics.zone** (DNS managed at Namecheap; Google Workspace email on the same domain).
- The intake **Google Form** is configured separately from this repo.
